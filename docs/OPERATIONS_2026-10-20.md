# 2026-10-20 출시 연결 및 운영 현황

## 완료

| 작업 | 결과 |
| --- | --- |
| 도메인 | ageclan.com과 www.ageclan.com을 기존 Sites 게임에 연결 |
| HTTPS | 두 호스트 모두 Sites status/provider/SSL active |
| DNS | Sites 발급 A 2개, www CNAME 1개, 인증 TXT 4개 등록 |
| 게임 | 두 새 호스트와 기존 chatgpt.site 주소에서 게임 200, 루트는 게임으로307 이동 |
| WebSocket | ageclan.com 실제 2인·5인 친구 방, 시작·설치·중복 명령·관전·재접속 통과 |
| 통신 표본 | 2인32ms·5인31ms. 대규모 부하나 최대 수용량 측정이 아님 |
| 기본 입구 보호 | Secure/HttpOnly/SameSite=Strict 세션, API no-store, 다른 출처403, 과대 본문413, 인증 없는 backend403 확인 |
| 랭킹 | 새 두 주소와 기존 주소의 서버 랭킹 조회200 확인 |

도메인 연결은 기존 v15에 대한 호스팅 변경입니다. 게임 규칙이나 DB 스키마를 변경하지 않았으며 대전 서버를 재배포하지 않았습니다.
DNS는 DNS only이며 트래픽은 Sites의 Cloudflare 사용자 호스트에 연결됩니다. 인증 TXT는 유지하세요.

## 현재 구조

브라우저 → Sites 게임과 같은 출처의 API/소켓 → 인증된 외부 대전 Worker → 방별 ClanRoom Durable Object.
D1은 방 검색·메타데이터·랭킹에 사용합니다. 명령은 서버 메모리에 먼저 적용해 응답하고 약2초마다 checkpoint합니다.
저장 장애·강제 종료 시 최근 진행이 되돌아갈 수 있고, 손실이 정확히2초 이내라고 보장하지 않습니다.

- 사용자 Cloudflare 계정: 도메인·DNS·대전 Worker·D1 관리.
- 기존 Sites 프로젝트: 화면과 API 입구 배포.
- GitHub: 소스 보관. push만으로 운영 자동 배포되지 않음.
- 기본 공유 주소: https://ageclan.com/game/
- www와 이전 주소도 같은 서버에 연결되지만 쿠키·localStorage는 주소별이므로 프로필과 업적이 자동 이전되지 않음.
- 도메인 전환 시 기존 계정 정보처럼 쿠키를 복사하거나 backend 키를 브라우저에 노출하지 않음.

최근 피드백의 밸런스, 광장·건설·시설 관리, 공격 연출, 선택창 깜빡임 수정,
음악·효과음, 군주 프로필·랭킹·업적 및 응답 개선은 v15에 반영되어 있습니다.
[반영 목록](FEEDBACK_RELEASE_2026-10-19.md)과 [보안 검토](SECURITY_RELEASE_2026-10-19.md)를 참고하세요.

## 남은 작업과 한계

1. 방당5명 기능 검증과 전체 서버 수용량은 다릅니다. 다수 방의 지속 부하·CPU·송신량·DB 사용량은 추가 측정이 필요합니다. 유료 전환이나 대규모 부하는 이번에 실행하지 않았습니다.
2. ML 라이브러리 설치는 학습 모델 완성이 아닙니다. 현재 저장본에 학습 코드·데이터·최종 모델이 없어 AI 대전을 연결하지 않았습니다. 관측/행동/보상 정의, 학습·평가, 추론 형식 결정이 필요합니다.
3. CPU/GPU 성능 진단용 MLP/1D-CNN과 게임 플레이 강화학습 AI는 별개입니다. 브라우저만으로 PC 전체 사용률을 정확히 수집할 수 있다고 가정하지 않습니다.
4. 기기 간 프로필·업적 이전을 위한 로그인 체계는 아직 없습니다.
5. 이전에 제외한 추가 건설·이미지 전면 개편·ML AI 대전·ML 자동 밸런스 변경은 이번 범위에 넣지 않았습니다.
6. 도메인의 TLS·세션·origin·본문 상한·backend 인증을 확인했지만 WAF 전체 설정·계정 MFA·전역 비용 제한·봇 방어·보관 정책 전체를 감사한 결과는 아닙니다. 기존 보안 검토의 보호 결과 접근 권한 한계도 유지됩니다.

## 비용과 관리

이번 연결에서 추가 유료 플랜이나 서비스를 구매하지 않았습니다. 도메인과 서버 사용량 요금은 별개이므로
무료 한도를 초과하는 사용량까지 무료라고 보장하지 않습니다. 인증 메일·결제·계정 보안 요청은 소유자가 직접 처리해야 합니다.
도메인 갱신 일정과 가격은 Cloudflare Registrar에서 확인하세요. 연결 작업은 갱신 설정을 변경하지 않았습니다.
