# 머신러닝 작업 공간

2026-10-18 현재 사용자의 학습 코드와 학습된 모델은 아직 작성 전입니다.
이 폴더는 작업 공간이며, AI가 이미 구현되었거나 게임에 연결되어 있다는 의미가 아닙니다.
`aGe Clan ML` 대화에서 검토한 Gymnasium / Stable-Baselines3도 현재 게임 의존성에는 포함하지 않았습니다.

## 추가할 파일

- `env.py`: 게임 상태를 관측값으로 변환하고 행동·보상·종료 조건을 정의하는 학습 환경
- `train.py`: 학습 실행과 모델 저장
- `evaluate.py`: 학습에 사용하지 않은 시드와 상대를 이용한 평가
- `requirements.txt`: 실제 사용하는 Python 라이브러리와 버전
- `models/`: 공개 배포할 최종 모델과 관측값·행동 순서·버전 설명

위 파일들은 이후 직접 구현할 목록이며 현재 존재하는 파일은 아닙니다.
Python 가상환경은 저장소에 넣지 않습니다. 학습 로그와 임시 체크포인트도 기본적으로 제외합니다.

## 게임과 연결할 지점

브라우저 혼자하기의 원본 규칙은 `public/game/game.js`, 서버에서 사용하는 생성본은
`lib/game-engine.js`, 대전 규칙은 `lib/match-engine.js`에 있습니다.
`npm run build`는 원본에서 서버 엔진을 다시 생성합니다. 생성본만 수정하지 마세요.

JavaScript 엔진을 Python에서 그대로 import할 수는 없습니다. Gymnasium 환경을 만들 때는
고정된 시간 간격으로 관측·행동을 교환하는 브리지 또는 별도 환경 구현이 필요합니다.
학습 시뮬레이션의 규칙이 실제 게임과 일치하는지도 검증해야 합니다.

학습은 Python 환경에서 수행하고, 사이트 배포와 구분합니다.
브라우저 실행 모델로 변환하거나 별도 Python 추론 서버를 연결할 수 있습니다.
현재 Cloudflare Worker는 Python 학습 프로세스를 실행하는 구조가 아닙니다.
향후 대전 AI를 추가할 때는 AI도 서버의 행동 검사를 거치도록 연결하고,
클라이언트가 보내는 자원·피해량을 신뢰하지 않는 현재 구조를 유지하세요.
