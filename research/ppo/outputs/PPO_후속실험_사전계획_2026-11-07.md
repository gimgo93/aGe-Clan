**PPO 후속 실험 사전 계획 · 2026-11-07**

NPU의 실제 추론 지연을 CPU와 비교하고, 현재 엔진에서 학습된 정책의 초반 건설·판매 반복을 줄이는 실험을 진행한다. 이 계획은 후속 학습과 새 검증 결과를 보기 전에 기록했다.

**장치 판단**

Intel AI Boost의 장치 상태와 드라이버를 확인한다. 고정 입력 148개, 출력 행동 로짓 173개인 현재 정책망을 OpenVINO로 변환한 뒤 같은 입력·마스크에서 CPU와 NPU를 측정한다. 기본 비교는 행동 하나를 순서대로 요청하는 batch 1 추론이다. 모델 컴파일 시간과 첫 실행 시간은 정상 상태 추론 시간과 따로 기록한다.

가능하면 실제 에피소드 5개에서 전체 처리 시간도 비교한다. 행동 일치율 99% 이상이며 실제 에피소드 처리 시간이 CPU보다 10% 이상 빠를 때 NPU 추론 채택을 검토한다. 역전파와 optimizer 갱신은 현재 CPU PyTorch 학습 경로를 사용한다. 드라이버나 변환이 실패하면 실패 원인을 기록하고 CPU에서 계획을 진행한다. 전력은 별도 측정 도구를 확보하지 못하면 미측정으로 기록한다.

**PPO 학습 실험**

현재 엔진의 기존 모델과 같은 관측 정규화를 이용해 초기 가중치와 학습 후 행동을 비교한다. 이어 성공한 규칙 봇의 학습용 에피소드 20개를 수집하고, 행동 모방으로 정책을 초기화한 뒤 PPO를 학습하는 후보와 기본 초기화 PPO를 비교한다.

두 후보는 같은 학습 seed마다 동일한 초기 네트워크에서 시작한다. 관측 정규화는 학습용 규칙 봇 자료에서만 구하고 두 후보가 똑같이 사용한다. 후보 간 차이는 정책망의 행동 모방 초기화다. 모방 단계는 실제 학습 연산으로 별도 기록하고, 각 후보의 PPO 상호작용 예산을 같게 한다. 후보의 전체 연산 예산이 같다는 주장은 하지 않는다.

모방 초기화 직후에도 개발 시드에서 평가한다. PPO 후 개발 성공 수, 평균 실제 연속 완료 웨이브, 낮은 누수 순서로 후보를 고른다. 최종 새 검증에는 고른 후보의 학습 seed 42·43, 같은 seed의 대조군, 기존 저장 모델과 규칙 봇을 포함한다. 새 검증을 보고 하이퍼파라미터를 바꾸지 않는다.

평가에는 성공률·연속 완료수·누수·피해·처치·실행 거절·건설/판매 횟수를 기록한다. 학습 자료에서는 teacher 행동이 실제 마스크에 합법적인지 확인한다. 저장 후 실제 모델·관측 정규화 재로딩과 환경 지문 검사를 수행한다. 성공에 미달한 경우도 모델과 전체 기록을 보존하고 다음 계획을 보고서에 제시한다.

**최종 검증 전 추가한 진단 · 22시 40분**

seed 42의 개발 성공이 모방 초기화 직후 10/10에서 PPO 후 9/10으로 줄었다. 최종 새 검증 결과를 보기 전에, 모방 초기화 직후의 두 seed 정책도 같은 최종 시드 20개에서 평가하도록 추가한다. 이는 모방 초기화와 후속 PPO의 기여를 비교하기 위한 진단이다. 기존 네 PPO 후보의 학습량·파라미터와 개발 기준의 후보 선택 방식은 유지한다. 추가 평가 40에피소드를 별도 기록한다.
