# aGe Clan 현재 기준과 검증 경계

2026-11-05 점검 기록. 최초 플레이·튜토리얼·공개 홍보 안내 개편은 이번 범위에서 제외했다.

## 최종 상태 보정

아래 초기 조사 당시의 미인증·503·검토 상태는 역사 기록이다. 최종 릴리스 상태는 [V567_RELEASE.md](V567_RELEASE.md)가 우선한다. 사용자가 배포를 승인한 뒤 외부 PvP Worker v567을 `3371a1f4-c92e-4bf9-a1bd-d87cd8fc87c0`으로 실제 배포하고 공개 API 및 2인/5인 소켓을 검증했다. 백엔드 소스는 `a7fb12ef2374f2aad2322ae727d2539602df3a61`이다. Wrangler 4.158.0 기반 미리보기에서 HTTP 503 회귀를 해소했으며 로컬 회귀는 14개 묶음이다. 독립 검토도 수행했다.

프런트는 이후 의존성 패치를 포함해 빌드·검증·패키징했으나 기존 Sites 소유 계정 접근이 없어 소스 push·버전 저장·배포를 하지 못했다. GitHub 원격도 변경하지 않았다. 브라우저 실제 화면 QA, 실제 Google 로그인 UI, 운영 D1 복구·WAF·경보, 계정 MFA 활성화와 통계 운영자 지정은 미완료다. 최종 의존성 경고는 Critical/High 0, Moderate 15이며 [별도 점검](DEPENDENCY_REVIEW_V567.md)에 범위를 기록했다.

## 제품과 실행 경로

- 2D 운영 게임: `public/game/`. Canvas 화면, `game.js` 규칙, `balance.js` 수치. 혼자하기도 서버 판정이며 인터넷 연결이 필요하다. 20웨이브 이후 무한 방어, 일반 5인 매칭, 친구 2~5인 대전이 현재 경로다.
- `tools/sync-engine.mjs`가 원본 게임/밸런스를 `lib/game-engine.js`로 생성한다. 생성본을 직접 편집하지 않는다. 이번 패치는 게임 규칙·밸런스를 변경하지 않는다.
- 브라우저 → Sites 게이트웨이 → 인증된 별도 PvP Worker → 방별 `ClanRoom` Durable Object. Sites DB의 통계/피드백과 외부 Worker DB의 계정/진행/매칭은 별도 저장소다.
- 소켓 명령은 메모리 상태에 반영한 뒤 응답한다. 약 2초 간격 DO 체크포인트, 약 5초 간격 D1 방 디렉터리가 뒤따른다. 확인 응답이 디스크 영속 완료를 보장하지 않는다. D1 디렉터리만으로 전투를 복원하지 않는다.
- 3D 시험판: `public/3D/`, 독립된 엔진 사본과 브라우저 혼자하기. Google/랭킹/대전 API가 연결된 2D 대체품이 아니다.
- ML은 별도 GitHub 브랜치의 오프라인 도구다. 운영 봇이나 자동 배포 장치가 아니다.

## 배포와 소스 증거

마지막으로 인증된 Sites 연결에서 확인한 운영 기준은 **v56**, 소스 `109e353fd10547432d8a716ff84da8544d646df9`, 배포 `appgdep_6aebab35c99c81919d29353b585e351b`, 완료 시각 2026-11-05 07:01:35 KST다. 이 소스에서 로컬 브랜치 `codex/security-ops-20261105`를 만들었다.

19:43 KST 공개 GET 점검: `/game/` 200, `/api/clan` ready/protocol 2/capacity 5/websocket/durable-object/d1. 공개 `game.js`, `balance.js`는 로컬 원본과 LF 정규화 SHA-256이 일치했다. 이는 외부 PvP Worker 내부 엔진의 동일성을 증명하지 않는다. 외부 Worker 활성 version ID·소스 SHA·실제 바인딩은 인증 확인 전 미확인이다.

이번 작업 후반 Sites 메타데이터 재확인은 `project_not_found`, 목록은 빈 배열을 반환했다. 마지막 확인 v56을 현재 배포라고 재확정하지 않는다. 기존 Site 연결/계정 확인 없이 새 Site를 생성하거나 재연결 대상으로 대체하지 않는다.

사용자는 브라우저/계정이 맞고 이 채팅의 Sites 연동이 없다고 확인했다. Plugin Management에는 Sites가 기본 설치·활성 상태로 표시되지만 이 프로젝트 접근 연결은 확인되지 않는다. 읽기 전용 인증/점검은 승인받았으며, Cloudflare Wrangler는 미인증이다. 현재 Wrangler OAuth에는 Worker·D1용 읽기 전용 범위가 없어 기본 쓰기 범위 로그인은 시작하지 않았다. 대시보드 접근 시도도 현재 채팅의 브라우저 오류로 차단됐다. 문서에 기재된 외부 Worker 주소의 비인증 공개 GET은 403을 반환했지만 배포 버전 증거는 아니다.

기계 판독 해시: `node tools/release-manifest.mjs <output.json>`. 전체 소스 파일의 raw SHA-256, 주요 엔진의 LF 정규화 해시, SQL migration 해시, 기준 commit/작업 상태를 기록한다. 출력 자체는 소스 추적 목록에서 제외해 자기 참조를 피한다. 이 명세를 프런트/외부 Worker 양쪽 배포 증거와 대조해야 한다.

## GitHub 브랜치 역할

2026-11-05 fetch 결과. Sites 소스 저장소와 GitHub 저장소의 HEAD는 다르다.

|---|---|---:|---|
| main | `2a1b9161164e2eee8882da9f3e91674456f1832e` | 0 / 0 | 기준 |
| codex/startup-performance | `2baffc79513ed6ba2c9cb9b94dd959e938b85115` | 0 / 2 | 미병합 |

## 현재와 과거 ML 구분

`ml/`의 PPO는 행동 학습 실험 이력이다. `balance_ml/`은 고정 정책의 게임 결과를 이용하는 밸런스 대리 모델·짝 비교 도구다. 과거 결과/가중치를 최신 엔진 학습 결과로 재명명하지 않는다. 기존 5,000판 결과의 `no_patch`, 자료가 부족한 effect-v2, 광부 22명/공통 RNG 연구는 증거와 한계를 보존할 역사 자료이며 운영 적용 승인이 아니다.

새 로컬 `codex/ml-safety-20261105`는 `ce768ed…` 위에서 정책 순서를 유지한 역할별 함수 분리와 프로세스 시간 제한만 추가했다. 정책 변경과 재학습은 없다. 실행당 기본 120초, 일반 agent는 남은 호출 시간 예산도 적용한다. 실패·시간 초과 판의 결과를 journal에 추가하지 않는다. 소스 지문이 바뀌므로 예전 run을 덮어쓰지 말고 새 run 이름을 사용한다. ML 엔진은 운영 2D 최신 엔진과 별도로 대조해야 한다.

## 이번 보안 변경과 한계

- API 본문은 복제 전에 바이트 수를 제한한다. 게임 2,048 / 계정 12,000 / 피드백 8,000 / 통계 POST 1,200·DELETE 500 bytes. 잘못된 UTF-8·비객체 계정 JSON도 거절한다.
- 방 DO 선택 전 ingress별 HTTP 3,600회/분, 소켓 60회/분을 D1 원자적 카운터로 제한한다. 신규 입장 12회/분은 유지한다. 통계는 ingress 60회/분, 전체 3,000회/분, 삭제 ingress 20회/분·전체 300회/분이다. 인스턴스 내 선행 필터만으로 분산 제한을 보장하지 않는다. NAT 이용자 영향·비용은 실제 부하로 추가 측정해야 한다.
- 브라우저가 보낸 전달 헤더를 신뢰하지 않는다. CF ingress는 가장자리에서, 게이트웨이 ingress는 공유 secret 검증 후에만 신뢰한다. 원본 IP는 DB 카운터에 보관하지 않는다.
- 로그인 소켓은 해시된 세션 ID와 만료 시각을 가진다. 명령/heartbeat·주기 작업 전에 확인하며 세션 폐기 DB 재확인 캐시는 5초다. 만료 시각 뒤 명령은 거절한다. DB 확인 실패는 연결을 닫는다. 실행 큐·DB 응답이 정체된 상황까지 정확히 5초 안의 연결 종료를 보장하는 것은 아니다.
- 활성 게임 중 로그아웃/삭제 금지는 유지한다. 다른 세션의 폐기·계정 삭제·DB 세션 만료도 열린 연결이 계속 권한을 유지하는 근거가 될 수 없다. 이를 계정 탈취가 입증된 사건으로 표현하지 않는다.
- 통계 철회 시 수집을 중단하고 성공 전 재시도 식별자를 보존한다. 실패/진행/성공 UI, 재접속·수동 재시도를 제공한다. 저장소가 거부되면 메모리 재시도 정보와 한계를 표시한다. 이전 POST가 멈춰도 삭제 요청을 시작한다. 삭제 트랜잭션은 지연 기록의 재생성을 차단할 해시를 최대 90일 보관한다. DB schema 변경 없이 기존 `clan_limits`를 사용한다.
- `CLAN_ADMIN_ACCOUNT_IDS`는 표시 배지만, `CLAN_ANALYTICS_ACCOUNT_IDS`는 보고서 조회만 담당한다. 기본 거부. 운영 allowlist는 아직 이관하지 않았다.
- HTTP 요청 집계는 전체 게임 명령 수가 아니다. WS 내부 명령과 연결 수는 HTTP 통계에 누락된다. 현재 로그·ping 진단으로 확인하는 범위와 비용/보관을 정한 집계 추가 작업을 구분한다.

## 검증 범위

로컬 보안/계정/엔진/게이트웨이/체크포인트/네트워크 복구/기존 UI 동작 회귀 13개 묶음 통과. 실제 로컬 Wrangler에서 2인·5인 WS, 명령 확인·중복 방지·관전·재접속 통과. ML Python 51개, 정책 전체 게임 5쌍+강제 상태 50쌍 일치. 최종 빌드 통과. 빌드된 Worker를 격리 workerd/Miniflare에서 실행해 본문 거절 반복·잘못된 UTF-8/객체·계정 상태·DB 삭제 후 지연 기록 차단도 통과했다.

Wrangler 4.92의 개발 프록시 경유 HTTP 시험에서는 이른 본문 거절 후 다음 POST에 503이 재현된다. 같은 빌드의 직접 workerd 검사는 통과했지만 프록시 경유 진단은 미해결로 남긴다. `tools/diagnose-dev-proxy.mjs`와 실패 로그를 보존한다. 이를 운영에서 재현된 장애나 해결 완료로 표현하지 않는다. 운영 반영 전 승인된 별도 스테이징에서 실제 가장자리 HTTP 경계를 확인한다.

폐기 가능한 SQLite fixture의 백업·복원·integrity 검사와 **운영 D1/DO 복구 연습은 다르다**. 후자는 미완료다. 실제 Google 계정 로그인 E2E, 모바일/데스크톱 화면 QA, 실제 Cloudflare 한도/WAF/비용 경보/백업/관리자 MFA/secret 권한은 검증 완료로 표시하지 않는다. 별도 검토 에이전트는 사용량 제한으로 실행되지 않아 독립 검토 완료로 세지 않는다.
