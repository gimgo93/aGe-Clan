# 3차 사전 계획: 기존 마스킹 모델의 추가 학습

가설: 마스크와 entropy 0.003을 유지하면서 경험을 더 모으면 한 기 건설 후 대기에 머무르는
정책이 더 나은 방어로 발전할 수 있다. 이번에는 학습량만 바꾼다.

- 부모: phase2-low-entropy-20261021의 seed 42와 43, 각각 32,768행동 완료 모델.
- 각 모델의 정책/optimizer/관측 정규화 통계를 이어받아 추가 32,768행동 학습한다.
- 누적 65,536행동/모델이며 이번 실행의 추가량은 합계 65,536행동으로 제한한다.
- 보상, 173개 행동, 148개 관측, 마스크, entropy 0.003, 학습률, rollout, CPU 1스레드는 고정한다.
- 정확한 게임 중간 상태 재개가 아닌 새 에피소드 시작이다. 과거 모델·통계를 덮어쓰지 않는다.
- 개발 평가: 동일한 seed 40000–40019에서 부모/재개 모델을 비교한다.
- 개발 결과는 생존 → completed → 처치 → HP → 보상 순으로 후보를 선택한다.
- 최종 판단: 새 seed 60000–60019에서 후보, 부모 마스킹 43, 비마스킹 최선 43,
  대기·무작위·규칙 기반 정책을 비교한다. 실패 행동 0도 확인한다.
- 실패 행동 감점 차이 때문에 raw reward만으로 후보를 채택하지 않는다.
- 운영 코드/배포/DB/OpenAI API는 사용하지 않는다. 예상 학습은 약 6분이며 10분 내의 제한된 실험이다.
