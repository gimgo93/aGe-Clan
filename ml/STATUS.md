- 브라우저 원본 엔진과 학습 브리지 상태 일치, 서버 match-engine 공유 경로 일치.
- Gymnasium 및 SB3 `check_env`, 동일 시드 재현, 프로세스 격리·정리.
- 종료/시간 제한, 보상, 불가능한 행동, 나무 생산, 포탑 판매.
- SB3 벡터 환경 자동 reset, 짧은 무작위 rollout.

초기 연결 검사에서 환경 테스트 8개와 학습 테스트 2개, Node 엔진 일치 검사를 통과했습니다.
당시 CMD 진입점으로도 64-step CPU 학습 후 두 평가 에피소드를 실행했습니다.
모델과 평가 결과는 로컬 `ml/runs/initial-cli-check/`에 있으며 Git에는 포함하지 않습니다.
평가 평균 보상은 약 -16.32, 두 에피소드 모두 성 함락으로 종료됐습니다.
실패 행동은 각각 110/113, 103/106으로 많았습니다. 이는 저장·재로딩 연결을 확인한 결과이며,
유용한 전략을 학습한 모델로 볼 수 없습니다.

관측 상한 infinity에 관한 Gymnasium 경고가 있습니다. 현재 관측은 적을 경로 구간별로 집계하는
부분 관측이며, 비마스킹 PPO는 많은 불가능한 행동을 선택할 수 있습니다.
MaskablePPO는 실제 엔진 판정의 action_masks()로 이를 제외합니다.
최신 실험에서는 생존 개선을 관측했지만 실전 성능과 학습 안정성을 확보한 상태는 아닙니다.
현재 환경 테스트 8개와 학습 테스트 4개, 5,709개 마스크/엔진 판정 대조가 통과했습니다.
완료된 모델/optimizer/정규화 통계의 학습 재개와 누적 step 기록도 테스트했습니다.
