# aGe Clan 2D 시작 화면 개편

운영 2D 게임의 시작 화면을 Hallmark 지침으로 재구성했다. 3D 경로와 대전 서버 코드는 이 변경에 포함하지 않는다.

- 기존 브랜드: aGe 로고, Noto Serif KR, 숲의 녹색·황동색·아이보리 유지.
- 새 구도: 새벽 성채 전경, 왼쪽 대형 제목, 상단 계정과 설정, 하단 네 가지 모드 선택, 기록·안내 메뉴.
- 배경: 내장 이미지 생성 도구로 제작한 타이틀 전용 삽화. 실제 플레이 화면 캡처가 아니다. WebP 367,798바이트.
- 기존 titleScreen 내 15개 ID, 모든 스크립트와 메뉴 핸들러 유지. 최신 익명 통계/계정 연동 변경을 보존했다.
- 개발용 비교 링크, 미리보기 표시, 대전 차단 스크립트는 운영 배포에서 제외했다.

## 검증

- 기존 UX 회귀 검사 및 UI/오디오 검사 통과.
- 로컬 실제 브라우저에서 320×568, 390×780, 768×1024, 1280×720 화면의 가로 넘침 없음.
- 친구 코드 입력 창 연결, 혼자하기 전장 진입 확인. 로컬 검증 서버의 시험 자원을 사용했으며 실제 대전 부하 검사는 하지 않았다.
- Hallmark 정적 검사의 Floor 오류 0개. 선택 영역 색상에 대한 광역 배경 경고는 ::selection만 대상으로 하므로 오탐으로 검토했다. Hallmark 자동 렌더러 대신 지원되는 브라우저 도구로 실제 화면을 확인했다.
