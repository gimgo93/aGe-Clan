# Google 계정과 기록 동기화

공개 게임: https://ageclan.com/game/

2026-10-21 변경: 업적과 랭킹은 로그인 계정만 이용합니다. 게스트 신규 랭킹 저장과 업적 갱신을 중단하고 서버 랭킹 조회도 인증을 요구합니다. [전체 운영 구조](ARCHITECTURE_2026-10-21.md)

Google 로그인 앱을 프로덕션으로 게시하고 실제 사용자 로그인을 확인했습니다. 게임 시작 화면의 **계정 · 기록 동기화**에서 로그인·저장·새로고침·로그아웃·삭제가 가능합니다.

## 저장 범위

- 사용자가 정한 군주 이름·아바타와 허용된 게임 설정
- 서버가 판정한 최고 웨이브·처치·시설·성장 기록 및 서버 랭킹
- 과거 브라우저 기록은 별도 가져오기로 보존하며 미검증 기록으로 표시합니다. 클라이언트 기록을 공인 서버 랭킹으로 올리지 않습니다.
- 전체 전투의 임의 시점 저장이나 여러 기기의 동시 조종을 제공하는 기능은 아닙니다.

Google 비밀번호·이메일·사진을 게임 DB에 저장하지 않습니다. Google 서명·발급자·대상 클라이언트·만료·일회성 nonce를 검증하고 계정 식별자를 해시해 사용합니다. 세션은 Secure/HttpOnly 쿠키이며 로그인 시 교체됩니다. 기기별 세션, 설정 버전 충돌 검사, 계정 삭제 후 늦게 도착하는 저장 요청 방지도 적용했습니다. 개인정보 안내와 이용약관은 게임에서 열 수 있습니다.

## 검증과 수정

`node tools/check-accounts.mjs`: 독립 세션 두 개의 기록/설정 동기화, 충돌, 로그아웃, 재로그인, 삭제, 서명·nonce 검증 등을 검사합니다. 실제 사용자 Google 로그인도 확인했습니다. 실제 두 대의 서로 다른 기기로 하는 최종 검사는 남아 있습니다.

종료한 대기방의 오래된 D1 색인 때문에 로그인 등이 계속 '게임 진행 중'으로 오인될 수 있던 문제를 수정했습니다. 실제 방 상태를 확인하고 입퇴장·연결 종료 시 색인을 갱신합니다. 계정 요청 횟수 제한과 만료된 인증 자료 정리도 추가했습니다.

PvP 명령은 서버 메모리에 반영해 응답한 뒤 약 2초 주기로 복구 상태를 저장합니다. 갑작스러운 서버 종료 시 그 사이 진행 일부가 되돌아갈 수 있는 반응속도 우선 방식이며 사용자가 승인한 설정입니다.
