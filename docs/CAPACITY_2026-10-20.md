# 동시 접속 측정 결과와 다음 시험 계획

측정일: 2026-10-20. **검증한 범위는 동접 20명·4개 방의 짧은 시험이며, 서버의 실제 최대 동접 상한은 미측정입니다.** 50명 이상 확대 시험은 사용자의 요청에 따라 진행하지 않았습니다.

## 시험 범위와 한계

- 운영 서버와 분리한 임시 Cloudflare Worker/Durable Object 환경, 방당 5명. 접속 경로는 **SEA**였으며 국내 ICN 경로 시험으로 해석할 수 없습니다.
- 후반 조건: 24웨이브 완료 후 25·26웨이브 동시 진행, 성 레벨 20, 광부 30명, 벌목 50명, 초기 포탑 22개. 사망과 자원 부족으로 시험이 끝나지 않도록 시험용 금·내구도를 높였습니다. 종료 시 플레이어당 약 39~45개 적, 17~22개 포탑이 관측됐습니다.
- 클라이언트마다 초당 1회 ping, 2초마다 설치/철거 명령. Node WebSocket 클라이언트이므로 화면 렌더링·휴대폰 발열·FPS를 검증하지 않았습니다.
- 시험용 입장 경로로 방을 준비했습니다. 운영 사이트 입장 제한과 학교·가정의 동일 IP에서 다수 입장하는 상황은 별도 시험이 필요합니다. 기존 입장 제한은 IP당 분당 12회입니다.
- 수신 JSON량은 20명 단계 약 2.50MB/s였지만 압축 해제 후 크기이고 준비 구간도 포함합니다. 실제 네트워크 대역폭·청구량으로 사용할 수 없습니다.
- 코드 내부 타이머의 0ms 작업 시간은 CPU 사용량의 증거가 아닙니다. Cloudflare 실행 시간 측정에는 런타임 제약이 있습니다. [공식 설명](https://developers.cloudflare.com/workers/runtime-apis/performance/)
- 실제 사용자 Google 로그인과 기본 2·5인 연결 회귀 검사는 별도로 확인했습니다. 이 결과를 20명 이상의 안정성 보장으로 확대하지 않습니다.
- 초기 시험의 잘못된 자원 설정 및 다른 네트워크·배치 조건에서 얻은 진단치는 위 표에 혼합하지 않았습니다. 시험 환경 조정이 운영 환경의 모든 800ms 지연을 해결했다는 뜻도 아닙니다.

## 무료 사용량과 운영 가능 시간

동접 성능과 일일 사용 한도는 별개입니다. 현재 방은 전투 중 200ms 타이머를 사용하므로 지속 실행 시간을 고려해야 합니다.

Cloudflare Durable Objects 무료 플랜의 일일 실행 시간 13,000GB-s와 방당 128MiB(0.125GB) 계산을 적용하면, 4개 방을 24시간 계속 실행할 때 43,200GB-s가 필요합니다. 다른 사용량을 무시해도 무료 실행 시간 예산은 4개 방 동시 운영 약 7시간 13분에 해당합니다. 이는 실행 시간 예산의 산술상 상한이며 실제 보장 시간은 아닙니다. 요청·CPU·SQL 읽기/쓰기 등 다른 한도가 먼저 도달할 수 있습니다. [공식 가격 및 무료 한도](https://developers.cloudflare.com/durable-objects/platform/pricing/)

따라서 **20명 단기 통과가 무료 플랜에서 20명 24시간 운영을 보장하지 않습니다.** 이번 작업에서 유료 플랜으로 변경하지 않았습니다.

## 다음에 측정할 항목 — 이번에는 실행하지 않음

1. **20명 장시간 시험:** 4개 방으로 30분부터 시작해 잔여 예산이 허용하면 60분. 초반부터 무한 웨이브까지 진행하고 메모리 증가, 체크포인트 쓰기, 방 종료 후 정리, 서버 재시작 복구를 확인합니다.
2. **50→100→200명 단계 시험:** 각각 10·20·40개 방, 단계당 5~10분. 앞 단계를 통과하고 잔여 무료 한도를 다시 확인한 경우에만 다음 단계로 갑니다. 별도 승인이 필요하며 자동 실행하지 않습니다.
3. **실제 이용 환경:** 국내 서로 다른 통신사·학교 Wi-Fi·모바일 데이터, PC와 휴대폰을 함께 사용합니다. 같은 IP의 동시 입장, 관전 전환, 대량 재접속, 브라우저 백그라운드 복귀, 불안정한 네트워크를 포함합니다. 화면 FPS·프레임 시간과 네트워크 지연을 구분합니다.
4. **기기 간 기록:** 같은 계정으로 서로 다른 실제 기기에서 설정 저장·새로고침·동시 수정 충돌·로그아웃·삭제를 확인합니다. 현재 두 독립 세션의 자동 검사와 실제 Google 로그인은 통과했으나 실제 휴대폰과 PC 조합은 미검증입니다.

각 시험은 분리된 환경에서 실행하며 시작 전 해당 계정의 Workers·DO·D1 일일 사용량과 한도를 확인하고 운영용 여유분을 정합니다. 청구 또는 사용량 조회가 불가능하면 확대 시험을 시작하지 않습니다. 시험 도구의 기본 상한은 20명입니다.

### 기록 및 중단 기준

- 매 단계 ACK·RTT·상태 간격 p50/p95/p99, 오류 비율, 연결 종료·재접속 복구 시간, 수신량, 발생기 지연을 기록합니다. Cloudflare 제공 CPU·오류·SQL 읽기/쓰기·실행 시간 지표도 수집합니다.
- ACK p95 300ms 이상 또는 상태 간격 p95 350ms 이상이 30초 지속되면 확대를 중단합니다. 왕복 p95 200ms 초과는 먼저 네트워크 경로를 분리 조사합니다.
- 예상치 못한 연결 종료, 판정/자원 불일치, CPU 제한 오류, 무료 한도 경고가 나오면 즉시 중단합니다. 일반 요청 오류가 60초 동안 1% 이상이면 실패로 처리합니다. 짧은 30초 검증에서는 기존의 오류 0건 기준을 유지합니다.
- 발생기 지연 p95 40ms 이상이면 서버 한계로 단정하지 않고 시험 장비 병목을 조사합니다.
- 임시 주소·Worker·시험 데이터는 종료 후 정리합니다. 유료 플랜 변경은 별도 승인 없이 진행하지 않습니다.

**현재 결론: 확인한 동접은 20명이며, 최대 동접 수를 확정하려면 위 장시간·확대·실기기 시험이 필요합니다.**
