# v567 릴리스

앱 릴리스 이름은 **v567**이다. Sites 저장 버전 번호는 서비스가 반환하는 자동 번호이며 임의로 567을 지정하는 API는 없다. 두 번호를 혼동하지 않는다.

## 디자인 보존

- 기존 타이틀 삽화, 원본 `style.css`, `title-hallmark.css`, 게임 자산을 삭제하지 않았다.
- 기본 화면은 **기존 디자인**이다. 설정 → 화면 스타일에서 **성채 UI 개선**을 켜거나 기존 화면으로 즉시 돌아갈 수 있다. 선택은 해당 브라우저에 저장한다.
- 개인정보 제어의 필수 스타일은 별도 `privacy-controls.css`라서 어느 디자인에서도 삭제 재시도가 작동한다.
- 배포 전 원본 Sites 소스 `109e353fd10547432d8a716ff84da8544d646df9`를 Git 태그 `design-before-v567`와 전체 ZIP으로 보존했다. 이 태그는 원래 디자인의 기준점이며 v567의 보안 코드를 되돌리는 명령은 아니다.

## 변경

앞선 보안 변경을 포함한다: 제한된 바이트 본문, DO 진입 전 ingress 한도, 소켓 세션 재검증, 통계 철회 재시도·지연 기록 차단, 배지/통계 권한 분리. 앱 버전과 서버 엔진/밸런스 해시는 건강 상태 응답에 표시한다. 실제 Worker version ID는 배포 반환값으로 별도 기록한다.

Wrangler를 4.158.0 및 맞는 Worker 타입으로 고정했다. `npm start`는 생성된 설정의 로컬 사본에서 폐기된 `legacy_env`만 제거한다. 배포용 생성 파일과 Worker 애플리케이션은 이 호환 처리로 바뀌지 않는다. 기존 4.92 개발 프록시에서 재현되던 이른 응답 후 503은 새 경로에서 HTTP 회귀를 연속 3회 통과했다. 최종 경로에서도 실제 2인/5인 소켓 검사를 수행했다.

## 배포 순서와 경계

사용자는 2026-11-05 남은 검증 및 배포를 승인했다. 외부 `age-clan-pvp` Worker는 21:01 KST에 version `3371a1f4-c92e-4bf9-a1bd-d87cd8fc87c0`으로 배포했다. 백엔드 소스는 `a7fb12ef2374f2aad2322ae727d2539602df3a61`이다. 이전 버전은 `b8f09a6b-9505-4655-a5de-ece9086ff0cb`, DB와 DO는 기존 것을 유지했으며 schema/class migration을 추가하지 않았다. 이전 배포 소스도 별도 백업했다. 기존 운영 Worker와 후보의 게임 엔진 번들 구간 SHA-256이 일치했다. 공개 API의 v567과 운영 2인/5인 소켓 검사를 확인했다.

기존 공개 Sites는 사용자가 현재 계정으로 접근할 수 없다고 확인했다. 따라서 원래 Sites 관리 권한이 복구되기 전 프런트 배포를 완료했다고 표시하지 않는다. 현재 계정에서 새 사이트로 대체하거나 DNS를 바꾸지 않는다. 백엔드 배포 성공 여부·새 version ID·실제 공개 API 결과는 인계 보고서에서 확인한다.

`CLAN_ANALYTICS_ACCOUNT_IDS`는 현재 미설정이다. 새 프런트의 보고서는 대상 계정이 명시되기 전 403이다. 배지 secret 값을 읽거나 표시용 목록을 묵시적으로 권한 목록에 복사하지 않는다.

## 검증과 미완료

14개 로컬 회귀 묶음, 빌드, 격리 workerd, 실제 HTTP·2인/5인 WS 검사를 수행한다. 독립 검토에서도 검증된 추가 보안/배포 차단 결함은 발견되지 않았다. 기존 격리 workerd 검사와 새 Wrangler 미리보기 런타임 검사는 서로 구분한다.

실제 화면 QA는 현재 채팅의 브라우저 제어 제한으로 미완료다. Cloudflare 계정 MFA가 비활성임을 읽기 조회로 확인했다. MFA는 사용자가 직접 설정해야 한다. D1·비용 조회는 현재 OAuth 범위에서 거절돼 실제 복원·비용 경보 점검도 미완료다. 미완료 항목을 전체 검증 통과로 세지 않는다.

## 프런트 의존성 후속 수정

백엔드 배포 후 최종 npm audit에서 발견한 의존성 경고 때문에 프런트 후보만 추가 수정했다. Next 16.4.5, React/React DOM/RSC 19.2.8, Vite 8.3.6, Cloudflare Vite plugin 1.67.0, Zod 4.6.7과 호환 보정, 취약한 전이 의존성의 패치를 포함한다. 이 후속 소스는 배포된 백엔드 commit과 구분한다. 백엔드의 외부 의존성은 jose뿐이며 프레임워크 패키지를 포함하지 않는다.

최종 audit는 Critical 0 / High 0 / Moderate 15 / Low 0이다. 경고를 모두 제거한 상태로 설명하지 않는다. 세 원인과 남은 범위는 [의존성 점검](DEPENDENCY_REVIEW_V567.md)을 참고한다. Miniflare 5의 공식 V4 옵션 변환기를 사용해 격리 Worker 검사도 새 도구 버전에서 유지한다.
