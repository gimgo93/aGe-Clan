# 3D Frontier — 독립 혼자하기 시험판

공개 진입: https://ageclan.com/3D

**이 폴더는 3D 전용입니다. 기존 2D 운영 게임은 `public/game/`에 그대로 유지합니다.**

## 실행과 구성

- `index.html`: 3D 시작 화면·HUD·게임 메뉴
- `main.js`: 브라우저 로컬 진행·구매·강화·화면 전환
- `world.js`: 3D 전장·광산·마을, 카메라, 모델·동작·공격 표현, 선택 판정
- `style.css`: 3D 전용 반응형 UI
- `engine/game-v1.js`: 2D 규칙의 고정 사본. 원본 출처는 Sites 소스 `98887de233329037fd176242d4ab2c8cf4be892b`의 `public/game/game.js`이며 SHA256은 `E898FC890E431B38919B3C44D4D3310385DBAC531CB9A0E2D6A26980735D2081`입니다.
- `engine/balance.js`: 3D 시험용 시작 자원. 2D 밸런스와 별개입니다.
- `vendor/`: Three.js 0.180.0의 배포 모듈과 OrbitControls, MIT 라이선스. 모든 모듈은 같은 사이트에서 제공하며 실행 중 외부 CDN을 호출하지 않습니다.

루트 프로젝트의 개발·빌드 명령을 사용합니다. 별도 앱 설치나 별도 도메인은 필요하지 않습니다. `app/3D/page.tsx`는 `/3D` 진입을 3D 페이지로 연결합니다. 정적 호스팅에서도 이 폴더를 웹 서버로 제공하면 독립 실행할 수 있지만 `file://` 직접 열기는 지원하지 않습니다.

## 체험 가능한 기능

- 실제 3D 지형·성벽·건물·병사·광부·벌목 인구
- 드래그 회전, 휠 확대, 우클릭 이동, 두 손가락 확대·이동, 기본 시점·회전 버튼
- 방어 시설 5종, 3초 건설, 종류 전체 5레벨 강화, 선택 시설 철거와 절반 금 반환
- 성채 20레벨·5문명, 내구도·공격력 보너스, 나무를 이용한 수리
- 광부 5→30명, 벌목 인구 0→50명, 작업 모습은 각 최대7명
- 첫 웨이브 30초, 이후 전투 종료 후20초, 수동 시작·2배속·20웨이브 승리·패배·재시작
- 천둥·서리 물약과 간단한 공격·채굴·벌목 동작
- 그래픽 품질 2단계, 선택 효과음, 설정 중 일시정지

## 운영 2D와 다른 시험 규칙

- 시작 금420·크리스탈24로 화면과 설치를 체험하기 쉽게 했습니다.
- 연구소와 천둥·얼음 연구는 처음부터 완료 상태입니다. 연구소 모델은 마을에 표시됩니다.
- 혼자하기로 20웨이브 완료 시 승리합니다. 2D의 무한 웨이브·PvP는 연결하지 않습니다.
- Google 로그인·공인 업적·서버 랭킹·실시간 대전·기기 간 저장은 포함하지 않습니다.
- 진행 중 게임은 새로고침·탭 닫기 시 초기화됩니다. 최고 완료 웨이브와 그래픽·효과음 설정만 이 브라우저에 저장합니다. 키는 `ageclan-3d-best-v1`, `ageclan-3d-quality-v1`, `ageclan-3d-sound-v1`이며 기존 2D 키를 쓰지 않습니다.
- 모델은 코드로 만든 가벼운 스타일의 3D 도형입니다. 사진 수준 모델이나 외부 리깅 모델은 포함하지 않습니다.
- WebGL 2를 지원하는 브라우저와 그래픽 가속이 필요합니다. 실제 모바일 기기별 FPS·장시간 안정성의 보장 수치는 아직 없습니다.

## 운영 데이터 분리

3D 페이지는 `/api/clan`, Google API, WebSocket 대전 또는 D1에 접근하지 않습니다. 기존 2D 계정 쿠키를 읽거나 2D 기록을 전송하지 않습니다. 도메인·정적 파일 호스팅만 공유합니다.

# 3D 연출 개편 (2026-10-24)

- 천둥: 클릭 시 비용을 지불하고 1초 동안 어두워진 뒤, 그 순간 전장에 있는 적에게 분기 번개·충격파·현재 체력 60% 피해가 함께 발생합니다. 실제 피해도 1초 지연됩니다. 2배속에서도 시전은 활성 플레이 시간 1초이며 설정·성채 창을 열면 시전도 멈춥니다. Web Audio 충격음은 강타 순간 재생하며 기존 음소거 설정을 지킵니다.
- 눈서리: 돌풍·회전 흐름·눈발 궤적을 더한 눈보라 4초, 적설 유지 1초, 해빙 2초. 눈은 매 시전마다 무작위 지면 구역과 일부 나무 꼭대기·가지·밑동에 소복하게 쌓이고, 대부분의 지면은 원래 모습을 유지합니다. 재사용 시 새 적설 위치를 정합니다. 5초 빙결, 비용 및 재사용 대기시간은 유지합니다.
- 자원 그림: `assets/gold.svg`, `assets/crystal.svg`, `assets/wood.svg`를 직접 제작했습니다. 외부 이미지 요청·추가 라이선스가 없습니다.
- 광부: 별도 3D 모델(작업복·보강 부츠·안전모 조명·배낭·양손 곡괭이)과 준비·타격·회복 동작. 최대 7명 표시 규칙을 유지합니다.
- 눈 입자는 재사용하며 높은 품질 1,800개, 낮은 품질 750개입니다. 적설은 인스턴싱으로 묶어 그리며 번개 임시 지오메트리·재질은 종료 시 해제합니다. 재시작하면 진행 중 시전·날씨도 초기화합니다. 움직임 감소 설정에서는 추가 섬광·긴 눈발 궤적을 생략합니다.
