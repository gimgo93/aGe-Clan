원본 `ageclan.com feedback.txt`의 마지막 `<구상해야하는 거>`는 구현 범위에서 제외했다.

## 화면과 진행

- 건설 메뉴는 텍스트와 나무 가격으로 표시하며 바로 건설 명령을 전송한다. 부족한 자원은 빨간 토스트로 알린다.
- 성 뒤편 광장을 새 지역으로 추가했다. 광장 탭 또는 성 근처에서 왼쪽으로 밀어 이동하고, 광장에서 오른쪽으로 밀면 돌아간다.
- 광장에는 민가·포장 광장·분수·깃발·보행 인물을 배치했다. 문명에 따라 민가 모습이 바뀐다.
- 연구소·훈련소는 광장에 표시되며 설치된 건물을 터치해 관리한다. 시설 창은 카드와 진행 막대로 정리했다.
- 교란병 폭탄은 약 1초 동안 목표로 날아간 뒤 실제 시설 파괴와 파편 효과를 발생시킨다.
- 금·크리스탈은 프로젝트가 직접 작성한 금속·결정 그라디언트 SVG로 교체했다.
- 시작 화면에 전체 화면 게임 안내를 제공하고 전장과 대기방의 반복 설명을 줄였다.
- 공격 물약 투척 이벤트를 방의 모든 플레이어에게 전달하고 사용자 이름을 함께 표시한다.
- 상대 선택 목록은 참가자 구성이 바뀔 때만 수정한다. 서버 패킷마다 열린 선택창을 건드리지 않는다.
- 참가 알림은 금속성 높은 음의 합성 효과, 음악은 낮은 드론과 조용한 단조 아르페지오로 변경했다. 음량·효과음 설정을 따른다.
- 군주 이름과 문장을 시작 화면에서 설정한다. HUD·대기방·공개 랭킹에 사용한다. 실명이나 연락처 입력을 요구하지 않는다.

## 랭킹·업적

- 전역 랭킹은 D1에 저장하며 상위 20개 기록을 표시한다. SQL `RANK()`를 사용해 1·2·3·3·5 방식으로 동점 처리한다.
- 브라우저가 보내는 점수를 받지 않는다. 혼자하기도 기존 Durable Object 서버가 진행을 계산하고 방어 완료 웨이브를 저장한다. 따라서 혼자하기에도 인터넷 연결이 필요하다.
- 프로필과 업적은 브라우저에 저장된다. 서버 랭킹의 익명 식별자는 HttpOnly 세션에 연결된다. 로그인 계정·다른 기기 동기화는 이번 범위가 아니다. 쿠키를 지우거나 다른 브라우저를 사용하면 별개 참가자로 취급될 수 있다.
- 10·20·30·50웨이브, 1,000처치, 성20, 광부30, 벌목100, 포탑5, 포션3종 연구, 크리스탈100의 11개 업적을 추가했다. 금색 메달 중앙에 해당 표식을 넣고 달성 시 체크한다.

## 반응속도·보안

- 사용자가 승인한 변경: 명령은 메모리에 반영한 뒤 저장 완료를 기다리지 않고 응답한다. 약 2초 간격으로 복구용 상태를 저장한다.
- DO storage `put`과 `setAlarm` 모두 `allowUnconfirmed`와 `allowConcurrency`를 적용했다. 서버 급종료 시 최근 약 2초 진행이 돌아갈 수 있다. 저장소 장애가 지속되면 이 손실 범위도 커질 수 있다.
- 느린 저장소 Promise를 고의로 대기시키는 검사에서 명령 ACK가 먼저 전송되는 것을 확인했다. 운영 지연 개선 폭이나 동시접속 한계를 보장하는 부하 검사는 아니다.
- WS 입구 빈도 제한, 관전·재동기화 요청 제한, HTTP 빈도 및 pending 상한, 방 생성 IP 해시별 제한, 오래된 방 정리, 피드백 서버 제한, 랭킹 조회 5초 캐시를 추가했다.
- 자세한 검토 범위와 한계는 `SECURITY_RELEASE_2026-10-19.md`를 참고한다. 도메인 등록·DNS 변경 자체는 이 피드백 작업에서 수행하지 않는다.

## 검증과 배포

- 엔진 밸런스, 30초 최초 웨이브, 위/아래 벌목 구역, 보간, 명령 중복 방지, gateway 검사를 통과했다.
- 로컬 실제 2인/5인 WebSocket·패치·관전·재접속·명령 ACK 검사를 통과했다.
- 실제 서버 혼자하기에서 2배속·웨이브 종료·D1 랭킹 저장을 검증했다.
- 브라우저로 시작 화면, 전장, 광장, 랭킹 화면을 확인했다.
- Cloudflare 대전 Worker, Sites 프런트, GitHub는 동일 소스를 기준으로 갱신한다. 배포 결과는 작업 완료 메시지에 별도로 기록한다.
