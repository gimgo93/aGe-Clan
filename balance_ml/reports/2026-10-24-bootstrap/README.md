- 모델은64개 tanh 무작위 특징+ridge 가중치 학습, bootstrap5개입니다. 실제 학습된 약50KB 가중치를 models/bootstrap에 보관했습니다.
- 모델 홀드아웃 오차4.86675웨이브, 정책별 상수 기준2.92667웨이브. **추천 보류(no_patch)**.

- 두 궁수 정책은 기준/후보 모두 평균15입니다. 이 작은 고정 정책 표본으로 모든 궁수 전략의 상한/인간 난이도/물약 필수성을 증명하지 않습니다.

- 최종 추천은 모델 품질 기준 미달로 보류했습니다. 후보를 게임 코드에 적용하거나 운영 배포하지 않았습니다.
