# 공개 상태 수집기

현재 사이트에 공개 GET만 전송한다. 방 생성/가입/로그인/전투 명령/DB 수정은 하지 않는다.
네 경로에 각각2표본, 표본당8초 제한과본문2MiB 제한을 둔다. 리다이렉트는 따라가지 않는다.
본문 원문과쿠키는 저장하지 않고 상태/응답 시간/API ready/정규화소스SHA256만 저장한다.

```bat
node ml/ops/test_monitor.mjs
node ml/ops/monitor.mjs
```

출력은 Git에서 제외한 ml/runs/ops에 새 파일로 저장한다. 기존 관측을 덮어쓰지 않는다.
네트워크가 제한된 실행 환경에서는 ENOTFOUND 등이 발생할 수 있으며 observation_incomplete로 표시한다.
이는 사이트 장애의 증거가 아니다. HTTP503 또는잘못된API본문은 issues_observed로 구분한다.
같은 파일 해시가 여러 번 달라지면 캐시/배포 변동일 수 있어 별도 확인한다.

GET API ready는 준비 확인이며 실제 방/로그인/WebSocket 정상 증거가 아니다.
두 개 HTTP표본을 전체 사용자 p95/오류율/동접수로 확대 해석하면 안 된다.
정기09시/21시 점검은 하루 중 발생한 모든 장애를 포착하는 상시 관제가 아니다.

전체 목표·난이도·시설 범위·알고리즘·필요한 실제 집계 자료는 [설계](../BALANCE_OPS_PLAN.md)를 따른다.
