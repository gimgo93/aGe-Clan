# 업적 알림과 게임 입장 UI

- 로그인한 이용자가 플레이 도중 새 조건을 충족하면 메달·업적명·조건을 3.5초간 알린다. 여러 업적은 순서대로 표시한다.
- 알림은 본인의 서버 스냅샷만 관찰한다. 로컬 명령 예측값으로 알림을 생성하지 않는다. 기존 계정 업적을 미리 등록하고, 중복 스냅샷·롤백·재접속에 중복 알림을 막는다. 페이지를 새로 열어 기존 게임에 복귀할 때는 첫 스냅샷을 기준 상태로 등록한다.
- 11종 메달을 하나의 투명 스프라이트 이미지로 제작했다. 각 달성 조건은 기존과 같고 잠금 상태·조건별 진행률을 표시한다.
- 업적/랭킹의 동기화·미검증 설명은 화면에서 제거했다. 비로그인 안내는 ‘설정에서 로그인 후 접속하세요.’와 설정 버튼으로 줄였다. 계정/기록 저장 방식은 그대로다.
- 혼자하기 준비 창, 공개 매칭, 친구 방 생성, 초대 코드 입력, 대기 참가자 목록을 같은 성채 테마로 구성했다. 8자리 코드 검사, 로딩 중 중복 제출 방지, 오류 표시, 닫기/퇴장, 네이티브 dialog의 키보드 접근을 유지한다.
- ‘제작 및 이미지 출처’ 버튼과 창을 제거했다. 자산의 라이선스 기록은 ASSET_CREDITS.md와 배포 파일에 유지한다.

## 이미지

내장 이미지 생성 도구로 하나의 4×4 투명 아틀라스를 생성했다. 앞 11칸에 성채, 성문, 전설의 요새, 불멸의 방패, 검, 도시, 곡괭이, 참나무, 발리스타, 물약, 크리스탈 훈장을 배치했다. 마지막 5칸은 비웠다. 문자나 UI를 넣지 않은 금속/석재 기반의 2D 전략 게임 훈장이다. `assets/achievement-medals-v1.webp` (472,814바이트, 1254×1254 RGBA).

## 검증

`tools/check-achievement-state.mjs`: 11개 조건, 기존 업적 무알림, 임계값 최초 통과, 중복 스냅샷, 롤백, 동시 달성, 계정 전환, 코드 연결 검사.
기존 UX·UI/오디오·PvP 회귀 검사 통과. 실제 브라우저에서 시험 서버의 10웨이브 상태로 알림 표시를 확인했으며 실제 플레이어의 기록을 조작하지 않았다. 게스트 로그인 안내와 새 입장 화면도 확인했다.
