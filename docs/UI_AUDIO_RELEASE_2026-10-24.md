## 사용자 요청 반영

- 비로그인 기본 이름은 형용사+상징+4자리 숫자, 문양은8종 중 무작위로 부여합니다.
- 탭의 sessionStorage에 유지하므로 새로고침/게임 재시작 때 이름이 바뀌지 않습니다. 새 게스트 세션은 다시 생성하며 브라우저 저장이 막혀도 메모리에서 동작합니다.
- 예전 age-profile의 고정 이름을 게스트 기본값으로 사용하지 않습니다. 게스트가 직접 편집한 이름/문양도 해당 세션에 보존합니다.
- 로그인하면 계정 프로필을 복원하며, 세션 만료/로그아웃 때 계정 이름이 게스트로 남지 않도록 복원 경로를 보완했습니다.
- 매칭 창의 '입장 알림음은 설정의 효과음과 전체 음량을 따릅니다.' 안내만 삭제했습니다. 실제 입장/시작 알림은 유지합니다.
- 랭킹/업적/설명 메뉴는 모든 화면에서 왼쪽 아래를 기준으로 정렬하고 짧은 가로 화면의 버튼 겹침을 해소했습니다.
- 본문·메뉴·입력 및 전장 canvas 글꼴을 Noto Serif KR 기반 명조/세리프로 통일했습니다. Google Fonts가 실패하면 바탕/명조 계열 시스템 폰트를 사용합니다.
- 캐시 혼용을 줄이기 위해 수정한 JS/CSS에 버전 쿼리를 추가했습니다.

## 소리

Web Audio 합성이며 외부 녹음 파일이나 생성 API를 사용하지 않습니다.
처치음은 짧고 작은 하강음, 크리스탈은 부드러운3음, 슬라이드는 필터를 통과한 바람 소리,
페이드는 천천히 부풀었다 사라지는2음으로 구분합니다. 클릭/실패/공격/채굴/건설/고용/강화/
웨이브/클리어/문명/물약/파괴/승패/입장/시작 효과를 제공합니다.

모든 효과음은 기존 효과음 토글과 전체 음량을 따릅니다. 첫 사용자 조작 전에는 AudioContext를 만들지 않습니다.
배경 음악과 효과음 버스를 분리하고, 종류별 재생 간격과 최대24개 음성, 종료 후 노드 해제로 소리 과밀/자원 누적을 제한합니다.
음소거는 이미 재생 중인 효과음 버스에도 적용합니다. 백그라운드 탭에서는 소리를 중단합니다.
서버 스냅샷의 처치/획득 증가분을 사용하므로 신규·중복·초기/방 전환 스냅샷을 구분합니다. 크리스탈 이벤트와 누적 획득치를 중복 재생하지 않습니다.
