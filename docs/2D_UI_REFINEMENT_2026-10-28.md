# 2D 화면·음악·진행 연출 개선

- 전장 오른쪽 드래그로 광장에 들어가는 제스처를 제거했습니다. 전장·광산·광장 버튼을 같은 세 칸에 배치하고 광장에는 별도 시설 관리 패널을 제공합니다. 시설 건설도 화면을 자동으로 바꾸지 않습니다.
- 앱 숨김·창 이탈·페이지 종료 시 음악 타이머와 재생 중 음원을 정리하고 AudioContext를 멈춥니다. 화면으로 돌아오면 사용자 설정에 맞춰 재개합니다. 로비는 별도의 장조 선율을 사용합니다.
- 성·포탑 강화는 짧은 황동색 윤곽과 레벨 표식으로, 문명 발전은 단정한 성채 배너로 바꿨습니다. 동작 줄이기 설정을 존중합니다.
- 배속의 실제 5초 제한은 유지하면서 숫자 대기 문구를 버튼 내부의 시계 방향 채움으로 바꿨습니다.
- 연구소 자원 부족 문구는 보유량을 빼서 부족한 나무 수를 표시합니다.
- 게임 설명에 자원·강화·조작·대전·연구와 적 6종의 등장 조건·특징·성 피해·교란병 폭탄·침공군을 추가했습니다.
- 결과 화면의 행동은 항상 게임 나가기이며, 승리와 패배를 색·문구·문장으로 구분합니다.
- 혼자하기의 게임 중 웨이브 표시는 20을 목표로 시작합니다. 첫 20웨이브를 모두 방어하면 게임을 종료하지 않고 한 번의 축하 배너와 함께 ∞로 전환합니다. 동시 웨이브에서 먼저 끝난 뒤쪽 웨이브가 개방 조건을 앞당기지 않도록 검사합니다. 메인 혼자하기 메뉴 문구는 유지합니다.
- 랭킹 1·2·3위에 직접 작성한 금·은·동 성채 훈장 SVG와 절제된 행 장식을 적용했습니다. 동점 등수 규칙을 그대로 따릅니다.

검증: 오디오 수명주기·새 로비 선율, 20웨이브 개방·중복 연출 방지, 서버 PvP·명령 큐·배속 잠금 검사. 로컬 합성 상태를 이용해 모바일/데스크톱 장면 이동·승패·축하·랭킹을 확인합니다. 합성 상태는 배포 소스에 포함하지 않습니다.
