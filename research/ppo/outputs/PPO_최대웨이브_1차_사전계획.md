**최대 웨이브 전환 1차 사전계획**

이번 회차는 20웨이브 목표로 훈련한 기존 기본/모방 초기화 정책을 target_wave=0으로 명시적으로 전이한다. 과거 실험 파일은 보존하고 work/ppo-maxwave-r1/engine 사본에서 실행한다.

- 학습 시드: 42, 43. 각 계열 추가 PPO 32,768스텝, 총 4회 131,072스텝. 각 모델 누적 PPO 65,536스텝.
- 엔진, 148개 관측, 173개 행동, defense-v1 보상, PPO 하이퍼파라미터는 유지한다. 목표 성공 보너스/목표 이후 시작 제한은 목표 해제로 비활성화된다.
- 프레임 스킵 10 유지. 최대 120,000틱(게임 시간 12,000초). 성이 무너질 때 종료하며 시간 제한은 검열된 하한으로 기록한다.
- 주 지표: 실제 연속 완료 웨이브. 최고 시작 웨이브, 평균/중앙값/범위/10·90백분위, 제한 종료 수, 잘못된 행동 수를 기록한다.
- 개발 평가 240000–240004, 최종 확인 250000–250019. 모든 모델에 같은 게임 시드를 적용한다.
- 후보 기준: 중앙값이 초급 20–25, 중급 30–35, 고급 40 이상에 해당하고 표본 80% 이상이 해당 구간이며 제한 종료가 없어야 한다. 초급은 기본 초기화 계열만 배정한다. 개발 평가로 각 계열 후보 시드를 먼저 선택하고, 최종 확인 결과를 별도 보고한다.
- 기본 계열은 무작위 가중치 계보지만 두 계열의 기존 관측 정규화에 공통 시연 통계가 들어갔다. 추가 시연/모방 비용 없이 부모 정책과 optimizer, 정규화를 이어 사용한다.
- 매 학습 직후 개발 평가를 수행하고 다음 회차 계획을 JSON으로 저장한다. 저성과는 행동 분포와 보상 항목으로 진단한 뒤 다음 보상 실험을 설계한다.
- CPU 사용: 기존 동일 정책 비교에서 작은 단일 입력 NPU 추론이 CPU보다 느렸다. 이번에 NPU를 다시 벤치마크하지 않는다.
