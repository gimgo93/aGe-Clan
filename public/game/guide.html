OWNER'S GUIDE

내 게임을 수정하고 배포하는 방법

설치 없이 브라우저에서 작동하는 2D 타워 디펜스입니다. 게임과 편집 도구의 원본 파일을 함께 제공합니다.

가장 쉬운 편집 순서

  1. 편집 도구에서 시작 자원, 웨이브 사이 대기 시간, 포탑 가격·공격력·공격 간격·사거리를 바꿉니다.
  2. 게임 미리보기로 초안을 확인합니다. 이때 본인의 브라우저만 바뀝니다.
  3. balance.js 다운로드를 누르고 내 PC의 sites/civilization-guardians/public/game/balance.js를 교체합니다.
  4. npm run build로 서버와 게임을 함께 빌드한 뒤 같은 Sites 프로젝트에 재배포합니다. 빌드 시 서버 전투 규칙에도 balance.js가 반영됩니다.

화면 배치나 게임 규칙을 바꾸려면 아래 원본 파일을 편집하거나, 이 사이트를 만든 Codex 채팅에 수정을 요청하면 됩니다. 운영 중인 서버 파일을 직접 바꾸는 실시간 CMS 방식은 아닙니다.

현재 배포 방식

현재 사이트는 공개된 Sites 클라우드 서버 + 데이터베이스에서 실행됩니다. 주소는 age-clan.elatedbadge256.chatgpt.site입니다. 별도 구매 도메인이 아닌 제공된 HTTPS 하위 도메인입니다.

혼자하기 파일은 정적 호스팅에서도 실행할 수 있습니다. 5인 대전에는 서버와 D1 데이터베이스가 필요하므로 파일만 올리는 정적 배포로는 대전이 작동하지 않습니다. Sites에서는 같은 프로젝트를 빌드·재배포하세요.

어떤 파일을 편집하나요?

파일편집하는 내용
public/game/balance.js시작 금·크리스탈, 전투 사이 대기 시간, 포탑 기본 수치
public/game/index.html메뉴, 버튼, 설명 문구, 창의 구조
public/game/style.css화면 비율, 배치, 크기, 색, 모바일 대응
public/game/game.js적·웨이브·전투·채굴·벌목·업그레이드 규칙
public/game/renderer.js전장·광산·병사·포탑을 그리는 방법과 애니메이션
public/game/app.js터치·마우스 입력, 화면 전환, HUD, 사운드
public/game/assets/배경·캐릭터·도끼·아이콘 이미지와 출처

PC에 Node.js가 있으면 사이트 폴더에서 npm run dev를 실행하고 표시된 로컬 주소를 여세요. 파일을 저장한 뒤 브라우저를 새로고침하면 됩니다. 인터넷 배포는 별도로 해야 합니다.

권한과 저장 범위

구분할 수 있는 일
사이트 소유자Sites에서 소스 수정·새 버전 배포·공개 범위 관리를 할 수 있습니다. 다른 호스팅은 본인 계정에서 권한을 관리합니다.
허용된 플레이어게임 플레이와 자신의 브라우저 설정 변경. 운영 중인 사이트 파일을 수정하거나 배포할 권한은 없습니다.
편집 도구 사용자자기 브라우저에서 초안 작성·미리보기·파일 다운로드. 공유 사이트 설정에 직접 쓰는 권한은 없습니다.
소스·이미지소스를 수정하고 다른 정적 호스팅으로 옮길 수 있습니다. 사용한 외부 이미지의 출처와 라이선스 문서는 배포물에 유지해야 합니다.

편집 도구의 주소를 숨기는 것은 접근 제어가 아닙니다. 현재 도구에는 서버 쓰기 기능이 없으므로 공개되어도 배포본을 바꿀 수 없습니다. 추후 웹에서 바로 저장·발행하는 관리자 기능에는 서버 인증과 권한 검사를 추가해야 합니다.

음량과 화면 전환 설정, 편집 초안은 현재 브라우저의 localStorage에 저장됩니다. 혼자하기 진행은 새로고침하면 초기화됩니다. 대전은 서버에 저장되며 같은 브라우저에서 90초 안에 재접속할 수 있습니다. 익명 브라우저 세션을 사용하며 정식 회원 계정·전적·순위 기능은 없습니다.

게임과 서버의 역할

혼자하기는 Canvas 2D와 JavaScript로 기기에서 실행됩니다. 대전은 서버가 시간·자원·건설·전투·승패를 계산하고 브라우저는 명령을 보내고 결과를 표시합니다. 약 0.6초마다 HTTPS로 동기화하며 다른 군주의 전장도 볼 수 있습니다. 대전은 공통 1·2배속이며 방 참가자 누구나 속도를 바꿀 수 있습니다. 자원·건설·연구·웨이브·전투에 함께 적용되고 설정창을 열어도 계속됩니다.

친구와 코드로 대전하기

  1. 시작 화면에서 방 만들기를 누르고 군주 이름을 입력합니다.
  2. 표시된 8자리 초대 코드를 복사해서 친구에게 알려줍니다.
  3. 친구는 코드로 입장에서 해당 코드를 입력합니다. 일반 매칭 참가자는 초대방에 배정되지 않습니다.
  4. 2~5명이 모이면 방장이 친구 대전 시작을 누릅니다. 5초 후 동시에 시작합니다.

대기방에서 방장이 나가면 남은 첫 참가자가 방장이 됩니다. 모두 나가면 방이 닫힙니다. 같은 브라우저 세션은 한 명으로 취급됩니다.

현재 방당 정원은 5명입니다. 서버 전체의 안정적인 동시접속 상한은 실제 운영 환경의 부하 시험으로 측정되지 않았습니다. 기능 검사 통과 인원은 서버 수용 한도를 보장하지 않습니다.

5인 대전 규칙

  1. 시작 화면에서 매칭을 누릅니다. 실제 플레이어 5명이 모이면 동시에 시작합니다. 같은 브라우저 세션은 한 명으로 취급됩니다.
  2. 나무 100개로 성 옆 훈련소를 설치하고 금 80개로 군사를 고용합니다. 대기 군사 최대 50명입니다.
  3. 자신이 20웨이브까지 모두 방어하면 상대를 골라 1~10명을 출병시킬 수 있습니다. 출병 대기는 8초입니다.
  4. 21웨이브 이후에도 계속 적이 나타납니다. 침공군은 가까운 포탑에 1.1초마다 55 피해를 주며 포탑 내구도는 300입니다.
  5. 마지막 생존자가 승리합니다. 90초 이상 연결이 끊기면 패배 처리됩니다.

매칭과 관전은 구현되어 있습니다. 웨이브는 각 플레이어가 따로 진행하며 2웨이브 동시 시작은 두 웨이브 모두 체력 1.2배가 됩니다. 대규모 동시접속 부하 검증, 순위전, 계정별 전적은 아직 포함되지 않았습니다.

연구소 · 수리 · 무한 방어

포탑 건설 3초, 훈련소 건설 8초, 포션 연구소 건설 10초입니다. 연구소는 나무 200개, 천둥과 얼음 연구는 각각 크리스탈 20개이며 30초 연구 후 아이콘이 열립니다. 천둥은 현재 체력 60% 제거, 얼음은 5초 완전 빙결이며 사용 비용 7·대기 2초입니다.

PvP 공격 약화 포션은 연구 30·사용 10 크리스탈, 10초간 상대 공격력 ×0.6, 중첩 가능, 대기 5초입니다. 성 수리는 내구도 20 회복이며 나무 비용이 5부터 두 배씩 증가합니다. 적 처치 보상은 2금입니다.

혼자하기도 20웨이브 이후 무한 진행합니다. 이후 적 수는 웨이브마다 1명 증가하며 HP와 이동속도는 1.1배씩 증가합니다. 설정의 의견 보내기로 작성한 의견은 운영 데이터베이스의 clan_feedback에 저장됩니다.
