# 2D 운영 게임 — public/game

이 폴더는 **기존 2D 운영 버전**입니다. 공개 주소는 https://ageclan.com/game/ 입니다.

- 전투·자원·화면 코드: `game.js`, `app.js`, `renderer.js`
- 운영 밸런스: `balance.js`
- 이미지·스프라이트: `assets/`
- 로그인·업적·랭킹: `account.js`, `chronicle.js` 및 서버 API
- PvP: `multiplayer.js`, 루트의 `lib/`·`build/pvp-worker.js`

3D 시험판은 **별도 `public/3D/` 폴더**에 있습니다. 이 2D 폴더의 파일을 3D 구현으로 교체하지 마세요. 전체 구분은 저장소 루트 `GAME_VERSIONS.md`를 참고하세요.
