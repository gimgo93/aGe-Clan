**NPU 측정과 채택 판단**

장치는 Intel Core Ultra 5 228V와 Intel AI Boost이며, NPU 드라이버는 32.0.100.4240이다. Windows 장치 상태는 OK였다. OpenVINO 2026.4.1-22982-e213a147257-releases/2026/4에서 CPU·GPU·NPU를 인식했다.

| 측정 | PyTorch CPU | OpenVINO NPU |
| --- | ---: | ---: |
| batch 1 행동 추론 지연 | 76.12µs | 634.98µs |
| 동일한 실제 5에피소드 합계 | 1.505초 | 2.226초 |
| CPU 대비 에피소드 처리 시간 | 1.00배 | 1.48배 |
| 같은 입력 256개의 행동 일치율 | 기준 | 100.0% |

입력은 정규화한 관측 148개, 출력은 행동 로짓 173개다. 각 400회 측정한 5라운드 평균의 중앙값을 추론 지연으로 기록했다. 마스크 적용·argmax를 포함하고 정규화와 게임 실행은 이 지연 측정에서 제외했다. 실제 에피소드 비교에는 정규화·마스크 요청·게임 실행을 포함했고 CPU와 장치 실행 순서를 번갈아 적용했다. NPU는 명시적으로 `compile_model(..., 'NPU')`로 지정했다.

NPU 모델 컴파일은 1.202초, 첫 추론은 30.36ms였다. 정상 상태의 NPU 추론은 CPU보다 약 8.3배 느렸고 전체 에피소드 처리 시간도 약 47.9% 늘었다. 5에피소드의 완료수·처치·누수·피해·종료 이유·행동 수는 CPU와 같았다. NPU 로짓의 최대 절대 오차는 0.000514였다.

같은 CPU 에피소드의 시간 분해에서 마스크 요청·판정·통신이 약 57.4%, 게임 진행 요청·계산·통신이 25.0%, 관측 정규화와 행동 계산이 17.4%였다. 작은 정책망의 행렬 계산을 가속해도 전체 처리에서 얻을 수 있는 이득은 제한된다. Python과 Node 사이 통신 시간은 각 요청 구간에 포함된다.

사전 채택 기준은 행동 일치율 99% 이상과 에피소드 처리 10% 이상 가속이었다. 속도 조건을 충족하지 못해 후속 학습과 검증은 기존 CPU 경로로 실행했다. 전력과 배터리 소비는 미측정이다. 측정에는 앞서 저장한 약한 정책 하나를 사용했으며, 같은 구조의 작은 망·순차 batch 1 요청에 대한 판단이다. 큰 모델·대량 배치의 NPU 성능으로 일반화하지 않는다.

OpenVINO는 Intel NPU 추론 경로를 제공한다. Stable-Baselines3는 CNN을 사용하지 않는 PPO에서 CPU 실행을 안내한다. 이번 판단에는 실제 장치 측정을 함께 사용했다.
