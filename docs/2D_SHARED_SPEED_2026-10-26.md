# 2D 같이하기 공통 배속과 방어 시설 강화 효과

## 동작

- 진행 중인 방의 생존 참가자는 방장 여부와 관계없이 1배속/2배속을 바꿀 수 있습니다. 4명이 참가한 친구방도 모두 같은 권한입니다. 기존 방 정원·매칭 규칙은 유지합니다.
- 서버가 명령을 순서대로 처리하고 공통 속도를 모든 참가자 상태에 저장합니다. 동시에 다른 속도를 요청하면 마지막으로 처리된 명령을 따릅니다. 변경자의 이름과 공통 속도를 방 전체에 알립니다.
- 이동·공격·채굴·벌목·건설·연구·재사용 대기·웨이브 대기를 함께 배속합니다. 접속 종료 판정·통신 주기·복구 저장 주기는 실제 시간을 유지합니다.
- 2배속 화면 예측에도 동일한 시간 배율을 적용합니다. 최종 자원·전투·승패는 서버가 계산합니다.
- 성채의 매 레벨 강화에는 금빛 고리·상승 입자·레벨 표시를, 포탑 종류 강화에는 해당 종류 전체에 푸른빛 고리·입자·레벨 표시를 추가했습니다. 효과는 약 2.6초입니다. 문명 변경 효과는 유지합니다.
- 새 게임·다른 참가자 관전 시 강화 표시의 기준을 초기화합니다. 움직임 감소 설정에서는 움직이는 입자를 생략합니다.

## 배포 범위

브라우저 2D 파일과 공통 게임 엔진, 방 서버의 `lib/match-engine.js`를 함께 배포해야 합니다. DB 스키마 변경은 없습니다. 기존 Worker의 DB·Durable Object·OAuth 변수·비밀 값은 유지합니다. 3D 코드는 변경하지 않습니다.

기존에 열어 둔 브라우저는 새로고침해야 새 배속 버튼이 보입니다. 온라인 방의 진행 속도는 서버가 전송한 상태로 복구됩니다.
