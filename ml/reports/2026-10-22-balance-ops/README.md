# 운영·밸런스 분석으로 전환한 첫 점검

사용자 목표: 첫판10–15웨이브,2–3판 후20,중수30,40부터 물약과고급 전략 필요.
실시간 플레이 봇의 자율 PPO학습을 보류하고 운영 상태 관측과 전역 시설 밸런스 분석을 우선한다.
전체 설계는 [BALANCE_OPS_PLAN](../../BALANCE_OPS_PLAN.md)을 따른다.

## 공개 사이트 관측

2026-10-22 22:12:39 한국시간, ageclan.com의 /game/, /api/clan,
/game/balance.js, /game/game.js에 각각2개 GET표본(총8개)을 관측했다.

- 모두 HTTP200. API 두 표본은 status=ready, transport=websocket.
- 준비상태 API 응답은494ms/271ms. HTTP요청 전체 시간이며 전체 이용자 지연/p95가 아니다.
- 배포된 game.js와balance.js의 줄바꿈 정규화SHA256은 로컬 파일과 모두 일치했다.
- API소스 GET은DB SELECT1과설정 준비 확인이다. 실제방/로그인/WebSocket/명령 성공은 미측정이다.
- 제한 환경에서 처음 발생한 DNS ENOTFOUND는 승인된 공개 GET 재시도에서 해소됐다.
  이를 사이트 장애로 보고하지 않는다. 공개 GET 결과만으로 운영 전체 정상도 선언하지 않는다.
- 실제 유저 동접/오류율/장기 지연/시설 이용률 데이터 연결은 아직 없다.

[public-status.json](public-status.json)은 관측 원본이다. 쿠키·응답본문·개인정보·키는 보존하지 않는다.
